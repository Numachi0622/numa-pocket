# numa-pocket

Markdown のタスクを Idea / Today / Done のボードで管理する Web アプリ。
GitHub のフォルダと、この PC のローカルフォルダを、名前付きワークスペースとして登録・切り替えできる。

## ローカルで使う

Node.js 22.12 以降または 24 以降が必要。

```sh
npm install
npm run local
```

[http://localhost:4173/numa-pocket/](http://localhost:4173/numa-pocket/) を開く。

1. 設定でワークスペースの名前を入力し、保存先に「ローカルフォルダ」を選ぶ。
2. この PC にあるタスクフォルダの絶対パスを入力して保存する。`~/` も利用できる。
3. 複数登録した場合は、画面左端のワークスペースタブで切り替える。

```text
設定
 ├─ 個人 → GitHub のリポジトリ / Task/Data
 └─ 仕事 → PC のローカルフォルダ
               ↓ 左端のタブで切り替え
       Idea │ Today │ Done
```

- フォルダ直下の `.md` だけが対象。1タスク = 1ファイル。タイトルはファイル名、列は frontmatter の `status: idea | today | done`。
- ローカルでも追加・列の移動・リネーム・削除をファイルに反映する。Git 操作や同期は行わない。
- ローカルサーバーは `127.0.0.1` だけで待ち受け、この PC のブラウザから使う。終了はターミナルで `Ctrl+C`。ポートの変更は `NUMA_PORT=4174 npm run local`（macOS / Linux）。
- GitHub Pages 上や `npm run dev` / `npm run preview` ではローカルフォルダ API は利用できない。
- 既存の GitHub 設定は最初のワークスペースとして引き継ぐ。設定は接続元ごとのブラウザ保存なので、GitHub Pages と localhost の間では共有されない。
- 設定の「登録を外す」はワークスペースの登録だけを外す。フォルダやファイルは消さない。
- 保存中は設定変更とワークスペース切り替えを待つ。取得後に変わったファイルは SHA で検出して保存を止める。
- 外部エディタとのファイルロックは共有していないため、検証直後から書き込みまでのごく短い間の同時変更を完全には防げない。外部アプリと同時に同じタスクを編集する操作は避ける。
- ローカルの削除はファイルを直接削除する。ごみ箱やアプリ内の取り消し機能はないため、必要に応じて自分のバックアップ・Git 履歴で復元する。

## PC とスマホでの操作

- PC: カードをマウスの左ボタンで押して移動するとドラッグできる。クリックだけなら編集。ドラッグ中の Escape で取り消す。
- スマホ: カードを長押ししてドラッグ。長押し前の指の移動は従来どおりスクロールとして扱う。
- 設定の「PC の列幅」で160〜800pxに変更できる。画面幅768px以上で適用し、スマホは従来の2列表示を維持する。
- 「端スクロールのゾーンの幅」は、ドラッグ中に左右の端で列を送るための判定範囲。列そのものの横幅とは別の設定。

## GitHub から使う

保存先に「GitHub」を選び、トークン・owner・repo・フォルダパスを指定する。
対象リポジトリだけに Contents: Read and write を付けた Fine-grained PAT を利用する。
読み込み・書き込みはデフォルトブランチが対象。トークンはブラウザの localStorage に保存する。

## 開発と検証

```sh
npm run dev
npm test
npm run typecheck
npm run build
```

GitHub Pages 向けの出力は `dist/`。ローカルファイル API は Node サーバー側だけにあり、Pages の配信物には含まれない。
`main` への push で GitHub Actions がデプロイする。
